HOW TO USE:
─────────────────────────────────────────────────────────────────────────────

1. Open AI Chat screen
2. Tap the microphone button (right side of input, when input is empty)
3. Speak your request clearly in Vietnamese
4. The recognized text appears in the input field automatically
5. Tap "Send" to submit

Visual Feedback:
• Mic button lights up (blue) while recording
• "Đang lắng nghe..." text shows real-time recognition
• Red dot indicates active recording

TO RUN THE APP:
─────────────────────────────────────────────────────────────────────────────

Prerequisites:
• Node.js >= 20
• npm packages installed: npm install
• iOS: pod install (already done)

Run on Android:
  npm run android

Run on iOS:
  npm run ios

Metro Bundler:
  npm start

TECHNICAL DETAILS:
─────────────────────────────────────────────────────────────────────────────

Hook Usage:
  const { 
    isListening,       // Is recording?
    recognizedText,    // Recognized text
    error,             // Error message
    startListening,    // Start recording
    stopListening,     // Stop recording
  } = useSpeechToText({
    onResult: (text) => { /* handle result */ }
  });

Platform Support:
  • Android: Full support (runtime permission request)
  • iOS: Full support (Info.plist permission)
  • Language: Vietnamese (vi-VN, vi_VN)

Error Handling:
  • "Không nghe thấy giọng nói" -> Speak louder/clearer
  • "Không có quyền..." -> Allow microphone in settings
  • Other errors -> Restart app and try again
